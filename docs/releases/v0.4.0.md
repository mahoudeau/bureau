One dashboard instead of two. The Desk at `/` shows what needs you and what's moving, and everything else got a page with its own address.

- **The Desk:** what needs you, what's in flight, PRs waiting to merge, your messages, the team, and the office in a window.
- **A page for everything:** every mission, goal, project and brain note, plus Settings for appearance, approval, roles, tokens and the MCP URL.
- **Buttons for what was API only:** delete or rename a project, discard a mission, remove an agent, start a goal.
- **Cmd-K** jumps to any page, project or mission, and searches the brain.
- **A new look** on OMAKO DS, our design system: dither instead of colour, in paper and ink.
- **Fixes:** the Desk reads roles from Settings, renaming a project keeps its settings, and a token with no event stream stops retrying every 3 seconds.

Nothing changes for the API or the agents. If a proxy sits in front of your hub, read UPGRADING.md, "0.4.0: the new dashboard": static files now come from `/app/` and `/omako-ds/`.

Docker: `ghcr.io/mahoudeau/bureau:0.4.0`. Everything that changed is in [CHANGELOG.md](https://github.com/mahoudeau/bureau/blob/v0.4.0/CHANGELOG.md).
