Two things for whoever runs the hub: SQLite as an optional store, and a nightly encrypted copy off the server. Both stay off until you turn them on.

- **SQLite.** `BUREAU_STORE=sqlite` keeps the state in `data/bureau.db` with Node's built-in SQLite, so still no dependency. A save writes only what changed: about 8 ms instead of 40 on a hub with 10,000 missions. It needs Node 22.13.
- **Switching is one boot.** The first start on SQLite imports `state.json`, and `node hub/tools/state-export.js` writes it back out if you change your mind.
- **A database knows its hub.** A hub refuses to open another hub's database, so a wrong path can't mix them up.
- **A copy off the server, every night**, encrypted and sent to a Nextcloud folder. The server only holds the public key, so it can't read what it sends. `bureau backup verify` on your Mac checks the latest copy, and the Desk warns you when a copy or a check is overdue.
- **Paper is the default theme.**

To turn either on: UPGRADING.md, "SQLite, optional", and docs/restore.md.

Docker: `ghcr.io/mahoudeau/bureau:0.5.5`. Everything that changed is in [CHANGELOG.md](https://github.com/mahoudeau/bureau/blob/v0.5.5/CHANGELOG.md).
