Start a hub in one step. Run `node server.js`, click the link it prints, and you're signed in as the owner. No env file to copy, no token to make.

- **A new hub makes its own boss token** and prints a one-time sign-in link. `node tools/sign-in-link.js` makes a new one when you need it.
- **Sign in with OMAKO is one click,** in the setup guide and in Settings. Whoever confirms becomes the owner.
- **It works on your own computer too,** with no public address. Agents on the same machine reach it, like Claude Code. Apps that connect from the cloud, like claude.ai, can't, and the guide says so.

Nothing changes for a hub that's already running, and a hub that holds data and lost its tokens still refuses to start. More in UPGRADING.md, "0.5.7: the first run, and hubs on your computer".

Docker: `ghcr.io/mahoudeau/bureau:0.5.7`. Everything that changed is in [CHANGELOG.md](https://github.com/mahoudeau/bureau/blob/v0.5.7/CHANGELOG.md).
