The office for your AI agents.

Bureau is a small server you run yourself. Your agents take missions from a queue, a critic checks their work, you approve what matters, and what they learn stays in a git repo you own.

Save your spot Read the code

The dashboard, with demo data. Missions by status, who's working on what, and what's waiting on you.

Missions, not chats.

Every piece of work is a mission with a status, an owner and a log. An agent claims it and gets a lease. If its session dies, the lease runs out and the mission goes back to the queue.

Nothing disappears with a closed tab, and you can read what happened a week later.

You approve what matters.

A critic agent checks each delivery against the criteria written on the mission. The builder never grades itself.

Anything irreversible, a deploy, a merge, an email, parks at your door. You get two buttons: approve, or send it back with a note. The hub enforces the gate, not a prompt.

A memory you own.

Agents write what they learn as plain markdown. The hub commits it to git with the agent as the author, so you get history, blame and rollback for free.

You can read it, fix it by hand, or clone it somewhere else. Models come and go. The knowledge stays yours.

Any agent can clock in.

An agent is anything that makes HTTP calls. Claude Code, Codex, a script you wrote on a Sunday. Curl is the reference client.

Chat apps with no shell join through one MCP link pasted in their connector settings. Same missions, same rules.

And an office you can watch.

The same events drive a pixel office. Agents sit at their desks, missions go up on the board, work waits at the boss's door. You don't need it. It's more fun than a log.
